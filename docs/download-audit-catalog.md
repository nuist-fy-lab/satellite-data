# Download catalogue audit

This is a semantic audit, not a live availability or download certification. The older `product-catalog-2026-09-27.csv` is a historical snapshot. Collection versions belong to their respective product families; do not apply a numerical MODIS version threshold across families.

| Source | Time and metadata considerations | Evidence and remaining checks |
| --- | --- | --- |
| GOES 16-19 | ABI imagery can follow scan modes 3, 4, or 6, with different full-disk schedules. Some ABI L2 products have real scan cadence, but a blanket L2 rule is not justified. GLM files cover event intervals. MAG is not an Earth disk scan. Version may be per file. | [NOAA ABI guide](https://www.ospo.noaa.gov/operations/goes/product-quality-overview/ps-pvr/goes-16/ABI/Cloud%20and%20Moisture%20Imagery/Full/GOES-16_ABI-L1b-CMI_Full-Validation_ProductPerformanceGuide_v2.pdf), [NOAA GLM guide](https://www.ospo.noaa.gov/resources/documents/PUG/GS%20Series%20416-R-PUG-L2%20Plus-0349%20Vol%205%20v3.0%20final.pdf). Provider overlap lookup is bounded to one hour for ABI L1b and GLM, 24 hours for other products; longer files can be missed. |
| Himawari 8/9 | Full-disk AHI has a nominal scan cadence; other sectors should not inherit it without evidence. | [JMA AHI](https://www.data.jma.go.jp/mscweb/en/himawari89/space_segment/spsg_ahi.html). Historical modes and overlap need independent verification. |
| MODIS / VIIRS | Five- or six-minute swath file duration does not imply a recurring wall-clock scan. Daily and composite products have separate coverage semantics. Collection existence and version are collection-specific. | [NASA CMR](https://cmr.earthdata.nasa.gov/search/site/collections). Verify actual granule coverage and access for each requested collection. |
| MTG | Full-disk FCI and quarter-disk rapid scan are distinct services; high spatial resolution alone does not establish a rapid-scan cadence. | [EUMETSAT distribution baseline](https://user.eumetsat.int/s3/eup-strapi-media/MTG_Products_Distribution_Baseline_MTGDIS_v4_B_8e06009946.pdf). The current whole-minute axis cannot represent 2.5-minute rapid scan. |
| EarthCARE | Orbit and auxiliary products do not necessarily have a spatial resolution or processing level. Do not promote file-level version to collection-level without evidence. | [ESA data offer](https://portal.maap.eo.esa.int/earthcare/earthcare-data-offer/). Verify each collection's actual coverage. |
| CALIPSO | Orbit tracks and period products require different controls; level and version come from the collection. | [NASA CMR](https://cmr.earthdata.nasa.gov/search/site/collections). Verify leading-boundary overlap for representative granules. |
| CloudSat | L0, L1B, L2B and L2C granules are orbit-level. Current provider search lacks granule end times and only returns starts in the query, so leading overlap is not established. | [CloudSat data guide](https://www.cloudsat.cira.colostate.edu/start-here). Do not invent orbit end times. |
| ERA5 | Reanalysis orders are generated separately from satellite archive granules; dataset-specific request schema and licence acceptance apply. | [CDS datasets](https://cds.climate.copernicus.eu/datasets). No real CDS submission was made in this audit. |
